# CosmOrganizer v3.2.0 - Release Notes (Aggiornato)

## 🌟 Focus sulla Semplicità e Core Performance

Questa versione v3.2.0 è stata ottimizzata per tornare alle funzionalità core che hanno reso CosmOrganizer uno strumento indispensabile, mantenendo però le innovazioni tecnologiche e grafiche delle ultime iterazioni.

### 🧹 Pulizia Automatica Cartelle (Mantenuta)

Mantieni il tuo sistema pulito senza sforzo:

- Opzione **"Elimina cartelle vuote"**
- Rimuove automaticamente le cartelle sorgenti che rimangono vuote dopo l'organizzazione dei file.

### 📦 Compressione Archiviazione (Ottimizzata)

Risparmia spazio sul disco in modo intelligente:

- Opzione per **comprimere file vecchi** (> 90 giorni) e di grandi dimensioni (> 10MB).
- I file vengono convertiti automaticamente in archivi `.zip` nella cartella di destinazione.
- Ideale per liberare spazio da vecchi file pesanti senza perderli.

### 📊 Dashboard e Interfaccia Premium

L'interfaccia utente è stata raffinata per un'esperienza più fluida:

- Visualizzazione immediata dello stato del monitoraggio e della destinazione.
- Statistiche rapide sul numero di file organizzati e spazio risparmiato.
- Design moderno con supporto completo alla Modalità Scura.

## 🔧 Miglioramenti Tecnici

- **Architettura Leggera**: Rimosse le regole personalizzate complesse per garantire la massima velocità di esecuzione.
- **Stabilità Real-time**: Migliorato il watcher dei file per evitare conflitti durante l'accesso.
- **Save System JSON**: Sistema di salvataggio impostazioni robusto e di facile manutenzione.

## 🐛 Bug Fix

- Risolti problemi di duplicazione dei processi in fase di avvio.
- Ottimizzata la gestione dei file bloccati da altri programmi.
- **UI Modern**: Implementati angoli arrotondati nativi (Windows 11).
- **Persistenza**: Le cartelle sorgenti vengono ora salvate tra una sessione e l'altra.
- **Controllo Sottocartelle**: Aggiunta opzione per includere o escludere le sottocartelle dall'analisi (disattivata di default per maggiore precisione).
- **Funzione Annulla**: Aggiunto tasto "Torna Indietro" per ripristinare i file nell'ultima posizione originale in caso di errore.
- **Feedback Migliorato**: Registro attività arricchito per mostrare ogni singola operazione (spostamento, compressione, skip).
